 # Артефакты проекта

В этой папке хранятся сохранённые результаты обучения и контрольные файлы проекта.

## Основная модель

- `best_model.pth` — финальная модель для инференса. Это ResNet-18 после fine-tune, выбранная как лучшая по качеству среди протестированных вариантов.
- `resnet18_frozen.pth` — промежуточная версия ResNet-18 с замороженными слоями; по качеству немного хуже финальной модели, но полезна для сравнения экспериментов.

## Кратко о результате

Финальная модель показывает лучшую точность среди основных экспериментов и используется в сервисе `POST /predict`. Для подробностей по обучению и метрикам см. `project/README.md` и `project/report.md`.
