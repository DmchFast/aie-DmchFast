# Исходный код проекта

В этой папке код проекта: загрузка и предобработка данных, определение модели, конфигурация приложения и точка входа сервиса.

Основные файлы:
- `app.py` — веб-сервис / API (эндпоинт `/predict`).
- `config.py` — настройки и константы проекта.
- `model.py` — определение модели и утилиты для инференса.
- `preprocess.py` — функции предобработки и трансформации данных.
- `__init__.py` — пакетная инициализация.
