# Конфигурационные файлы

В этой папке хранятся **настройки и конфигурация проекта**:

**Файлы:**
- `config.yaml` — описание архитектуры модели (имя модели, размер входа) и список классов.
- `classes.json` — JSON-список классов для модели (buildings, forest, glacier, mountain, sea, street).
- `.env.example` — шаблон переменных окружения (без реальных значений).

**Переменные окружения (.env):**

Реальные параметры хранятся в локальном файле `.env` **(не коммитится в репозиторий и добавлен в `.gitignore`)!!!**:
- `MODEL_PATH` — путь к сохранённой модели (по умолчанию `artifacts/best_model.pth`).
- `LOG_LEVEL` — уровень логирования (по умолчанию `INFO`).
- `CLASSES_JSON` — путь к файлу классов (по умолчанию `configs/classes.json`).

Шаблон для локального использования приведён в `.env.example`.
