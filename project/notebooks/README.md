# Ноутбуки проекта

В этой папке находятся Jupyter-ноутбуки проекта, используемые для исследования данных, базовой проверки моделей и экспериментов с переносом обучения.

Содержимое (основные файлы):
- `01_eda.ipynb` — разведочный анализ (EDA), визуализации и проверка качества данных.
- `02_baseline_ml.ipynb` — реализация и оценка базовой ML-модели.
- `03_transfer_learning.ipynb` — эксперименты с transfer learning (ResNet и подобные).
