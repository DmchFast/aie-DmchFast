# Тесты проекта

В этой папке находятся тесты, покрывающие API и модульные проверки логики модели и предобработки.

Файлы:
- `conftest.py` — фикстуры для тестов.
- `test_api.py` — тесты для API (эндпоинты и интеграция).
- `test_model.py` — модульные тесты для функций модели и инференса.

Запуск тестов:
- Выполнить `pytest -q` в корне проекта.
