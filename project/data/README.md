# Данные

Датасет Intel Image Classification доступен по ссылке:
https://www.kaggle.com/puneet6060/intel-image-classification

## Инструкция по загрузке
1. Скачайте архив с Kaggle.
2. Распакуйте содержимое в папку `data/raw/` создав `raw`.

Обратите внимание: сама папка `raw` и `processed` добавлены в `.gitignore`, чтобы не загружать большие файлы в репозиторий.
